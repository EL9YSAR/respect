موقع مفاجأة شذى ♥️

1) افتح index.html لمشاهدة الموقع.
2) لو عايز الموسيقى تشتغل داخل الموقع، ضع ملف الأغنية الذي تملكه/لديك حق استخدامه باسم:
   assets/song.mp3
3) الصورة موجودة بالفعل في:
   assets/photo.jpg

الموقع مصمم للموبايل والكمبيوتر، وفيه:
- صورة الذكرى
- رسالة الحب
- خط زمني لأهم تواريخكم
- أنيميشن قلوب
- مشغل للأغنية
